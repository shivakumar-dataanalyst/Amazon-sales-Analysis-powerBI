# Amazon Sales Analysis Dashboard – Power BI

## Project Overview
This project analyzes Amazon sales data using Microsoft Power BI.

## Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Average Order Value

## Dashboard Analysis
- Monthly Sales & Profit Trend
- Sales by Category
- Order Status Analysis
- Sales by State
- Sales by Payment Method
- Top 5 Products by Sales

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Skills Demonstrated
- Data Cleaning
- Data Visualization
- DAX Measures
- Interactive Slicers
- Business Insights
